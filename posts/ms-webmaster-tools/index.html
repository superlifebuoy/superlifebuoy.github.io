如何将网站加入 Bing 搜索引擎？

2025年11月5日

之前在《如何将网站加入Google搜索索引？》中，已经把自用的 blog 站点接入了 Google Search Console。最近继续尝试接入 Microsoft Webmaster Tools。

之前在未主动将网站加入各个搜索引擎索引时，分别用它们搜了一下nimblecode.tech。发现Bing动作最快，已经加入了搜索索引 ^o^~

1 Webmaster Tools 介绍#

Webmaster Tools 是由微软提供的一项免费服务，目的在于帮助网站所有者、SEO 专业人员和开发者监控、维护和优化其网站在 Bing 搜索引擎中的表现。

本质上，它的功能与 Google Search Console 类似，但专门针对 Bing 搜索引擎提供数据和优化建议。

2 接入 Webmaster Tools#

如果之前已经接入过 Google Search Console，那么接入 Webmaster Tools 就非常简单了。因为它会尝试从 Google Search Console 读取配置并自动导入，大大降低了接入成本。

首先打开 Webmaster Tools 网页。

注册/登陆后，Webmaster Tools 给了两个选项：“从 GSC 导入你的网站”、“手动添加网站”。

如果之前没有接入过 GSC，就选择“手动添加网站”，之后的流程逐步完成配置即可。如果之前已经接入了 GSC，则选择“从 GSC 导入你的网站”。这样 Webmaster Tools 会自动把 GSC 中的配置信息，导入到自己这边。

这个过程中，“bing.com” 会尝试获取用户 Google 账户下 GSC 数据的访问权限。

通过授权后，就可以选择哪些站点导入 Webmaster Tools 了。这里选择nimblecode.tech

点击“导入”就完成了整个流程。非常便捷。

进入 Webmaster Tools 后的第一步，依然是提交网站地图。

至此，接入 Webmaster Tools 的过程就完成了。

3 执行“站点扫描”#

在等待 Bing 爬取网站的同时，可以并行执行 Webmaster Tools 提供的“网站扫描”功能。

它可以分析你的网站，以查看是否存在常见的技术 SEO 问题，帮助用户修改这些问题以提高 Bing 搜索引擎的性能。

整个“站点扫描”过程，一般在48小时内完成。之后就可以看到扫描结果了。

如果发现了问题，根据 Webmaster Tools 的提示修复即可。
